# Lab 01b: Delivery Fee Calculator

This program calculates a delivery fee based on the user's order total and the day of the week.

The user enters their order total and chooses a day of the week. The program then uses both inputs to determine the delivery fee.

## Setup

This program was created using VSCode in Python in a Jupyter Notebook. 

## Run

Open `Lab_01b.ipynb` and run the code cell.

Enter the order total when prompted, followed by the day of the week.

## Example

Please enter the order total with no special characters: 15
Please enter the Day of the week: Saturday

Your order total is less than $20 and it is a weekend. You will be charged a $5 delivery fee.

## Known Limitations

The day of the week must be entered with the first letter capitalized, such as `Monday` or `Saturday`. The program accepts order totals up to $250.
